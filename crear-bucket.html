Crear bucket BRIMMO

Un paso único para dejar el storage listo. Después de esto, ya podés subir fotos desde el admin.

  1. Abrí el panel de Supabase de la instancia: api.neura.com.py
  2. Andá a Project Settings → API
  3. Copiá la clave service_role (la de más abajo, la que dice “Reveal” para verla)
  4. Pegala acá abajo y apretá el botón
Cuidado: la service_role da acceso total. Solo se usa acá, no se guarda, no se envía a ningún lado que no sea la propia API de Supabase. Cuando termine el paso, cerrá esta pestaña.
